# 《青原区营商环境监督参与意向调查》短信调研操作手册

本文适用于已经完成“调研对象”和“短信模板”配置的《青原区营商环境监督参与意向调查》问卷。手册按照系统当前页面和实际功能编写，说明每个选项的含义、适用场景、操作顺序和结果判断。

## 一、先理解本次调研的两种模式

进入问卷后，打开左侧 **调研对象**，顶部的“调研设置”中有两个模式。模式决定系统怎样保存邀请、怎样统计填写结果，以及后续能不能按人催答。正式创建第一个邀请批次后，模式会锁定；如果选错，需要复制问卷后重新设置。

| 选择 | 代表的特性 | 适合场景 | 后续能看到什么 |
|---|---|---|---|
| **匿名调研** | 短信邀请只关联到一个批次，不把手机号和具体答卷绑定 | 只想了解总体意见，不需要知道哪位联系人填写；对参与者隐私要求较高 | 可以看到批次访问次数、匿名答卷数量等总体数据；不能判断某个手机号是否填写，也不能导出逐人未完成名单 |
| **跟踪邀请进度** | 每位联系人生成独立邀请标识，访问、填写和答卷可以归因到该联系人 | 需要跟进未填写人员、查看访问进度、分组统计或人工催答 | 可以看到“未访问、已访问未完成、已完成”，完成后可以从联系人列表查看关联答卷；填写页会向参与者提示这是跟踪邀请 |

### 模式选择建议

- 如果本次重点是“收集总体意见”，不需要逐人追踪，选择 **匿名调研**。
- 如果本次需要对企业、联系人或分组进行参与情况跟踪，选择 **跟踪邀请进度**。
- 选择跟踪模式并不等于身份认证。链接可能被转发，系统只能确认“这个邀请链接提交过答卷”，不能证明提交者本人就是短信收件人。
- 匿名模式下仍然可以发送再次邀请，但不能自动排除已经填写的人；再次邀请前必须人工确认范围。
- 跟踪模式下，系统可以在催答时自动排除已完成、已访问未完成、未访问等不同对象。

## 二、配置完成后，正式发送前必须检查的事项

### 1. 确认问卷已发布

短信邀请只允许发送给已发布的问卷。进入问卷的 **发布** 页面，确认问卷处于可填写状态，并确认公开填写地址可从外网访问。短信中的邀请链接不能使用 `localhost` 或仅内网可访问的地址。

### 2. 确认短信平台能力已开启

进入 **系统配置 → 短信配置**，检查以下开关。按钮不可用或页面提示“尚未完成正式接口验证”时，不要绕过页面直接发送。

| 配置项 | 开启后代表什么 | 关闭时的影响 |
|---|---|---|
| 调研短信能力 | 允许创建问卷短信批次并进入发送队列 | 只能维护对象、模板和预览，不能创建真实发送批次 |
| 文本模板申请 | 允许通过开放接口提交新短信模板 | 不能点击“提交申请”；已有模板绑定不受影响 |
| 模板审核查询 | 允许查询云信模板审核状态和运营商覆盖 | 模板审核状态可能显示“未查询”，正式发送前无法完成审核校验 |
| 回执查询 | 允许同步提交、发送和送达结果 | 批次仍可能发送，但详情中的送达状态不会自动更新 |
| 上行回复查询 | 允许同步短信回复内容 | 回复收件箱不会自动取得新的上行记录 |

### 3. 检查短信模板

进入问卷左侧 **短信模板**，找到已经配置的模板，检查以下内容：

1. **名称**：只是系统内的识别名称，可以写“青原区营商环境监督参与意向调查邀请”。
2. **云信模板 ID**：必须与服务商审核通过的模板 ID 完全一致。
3. **类型**：
   - **变量文本**：正文包含 `#params_1#` 等变量，发送时按联系人或邀请链接替换变量。
   - **普通文本**：正文不使用变量，所有人收到同一条完整内容。
4. **完整正文**：必须与服务商审核通过的正文一致，包括签名、标点、空格和链接结构。系统本地修改不会同步修改服务商审核内容。
5. **变量映射**：决定每一个 `#params_N#` 最终放入什么值。常见来源如下：

| 变量来源 | 发送时的实际内容 | 适用场景 |
|---|---|---|
| **邀请标识** | 每条邀请的唯一标识 | 跟踪模式推荐使用，可记录访问和答卷归属 |
| **完整邀请链接** | 完整的公开填写链接 | 模板允许一个变量放完整链接时使用 |
| **链接分段** | 把较长链接拆成多个变量，每个变量一段 | 服务商模板变量长度受限时使用 |
| **问卷编号** | 当前问卷的编号 | 普通公开地址或不需要逐人归因时使用 |
| **问卷名称** | “青原区营商环境监督参与意向调查” | 需要在短信中显示问卷名称时使用 |
| **联系人姓名** | 调研对象姓名 | 需要“您好，某某”这类个性化内容时使用 |
| **联系人单位** | 调研对象单位 | 需要在短信中显示单位名称时使用 |
| **固定文字** | 对所有人都相同的文字 | 签名后缀、固定说明等 |

#### 五段链接模板的含义

如果模板正文配置了连续的 5 个链接变量，点击“连续5变量配置为链接分段”后，系统会把第 1 至第 5 个变量分别标记为第 1 至第 5 段。每段必须是非空值，并且不超过服务商允许的变量长度。不要手动把第 2 段配置成第 1 段，也不要遗漏中间段，否则预览会提示变量异常。

模板列表中的“审核状态”和“运营商覆盖”必须核对。覆盖显示“未知”时，发送前需要由操作人员确认是否接受当前覆盖范围；不能把“未知”当成“全部可用”。

## 三、从配置完成到首次发送的推荐流程

以下是本次《青原区营商环境监督参与意向调查》的推荐流程：

**选择调研模式 → 发布问卷 → 检查模板审核 → 确认对象名单 → 创建批次 → 预览 → 人工核对 → 确认创建 → 查看详情 → 同步回执 → 查看统计。**

### 第一步：选择匿名或跟踪模式

进入问卷 → **调研对象**，选择模式并点击 **保存设置**。

- 推荐需要后续催办、按单位查看完成情况时选择 **跟踪邀请进度**。
- 推荐只做总体意见收集时选择 **匿名调研**。
- 看到“已创建正式邀请，填写方式已锁定”后，不能直接切换模式。

### 第二步：进入短信邀请页面

进入问卷左侧 **短信邀请**。页面顶部会显示当前模式和短信能力状态。

点击 **发送邀请**。如果按钮不可用，通常是以下原因之一：短信调研能力未开启、问卷未发布、当前账户没有权限、或后端尚未完成必要的接口配置。

### 第三步：填写批次基本信息

| 字段 | 怎么填写 | 影响 |
|---|---|---|
| **批次名称** | 例如“青原区营商环境监督参与意向调查-首轮邀请-2026年10月” | 仅用于后台识别和统计筛选，建议包含轮次和日期 |
| **短信模板** | 选择已审核并核对过的模板 | 决定正文、变量数量和邀请链接形式 |
| **执行时间：立即进入发送队列** | 适合现在就开始发送 | 批次创建后进入待执行队列，系统在允许时段发送 |
| **执行时间：预约发送** | 选择北京时间日期和时间 | 到预约时间后进入队列；预约时间已过会被拒绝 |

系统默认只在配置的发送时段运行，通常为北京时间 8:00—20:00。预约时间不等于短信在该秒全部发完，实际发送还会受队列、分片和网关响应影响。

### 第四步：选择发送对象

有两种选择方式：

#### 按分组 / 单位选择

- **分组留空、单位留空**：选择当前问卷下所有符合条件的启用联系人。
- **只填写分组**：只选择该分组的联系人。
- **只填写单位**：只选择该单位的联系人。
- **同时填写分组和单位**：只选择同时满足两个条件的联系人。

这种方式适合按“企业组”“重点企业”“首轮样本”等名单整体发送。

#### 选择具体联系人

切换到“选择具体联系人”，在搜索框中按手机号、姓名或单位搜索，勾选指定联系人。适合补发、抽样试发或只联系少量对象。

系统会自动排除停用、账户级拒收、24 小时内已经发送、存在待处理记录或受理结果未知的对象。被排除的数量和原因会在预览中单独显示，不会悄悄混入发送数量。

### 第五步：点击“预览并检查”

预览是正式创建批次前的必要步骤。重点检查：

- **选择人数**：根据分组、单位或具体联系人得到的原始人数。
- **可发送人数**：扣除停用、拒收、重复发送、未知状态等对象后的数量。
- **变量异常人数**：联系人姓名、单位或链接变量缺失、超长时会出现。异常人数不为 0 时不能确认创建。
- **排除原因**：逐项查看为什么有人没有进入本次发送。
- **短信示例**：核对签名、问卷名称、链接、联系人姓名和单位是否正确。
- **运营商覆盖**：如果移动、联通、电信状态不是全部明确可用，核对后勾选“已核对运营商覆盖”。

#### 匿名模式的额外确认

如果普通文本模板中没有完整的批次邀请链接，匿名模式可能显示“固定正文未含批次邀请链接”。勾选“接受该批次无法统计访问和回收归因”后才能继续。这表示短信可以发送，但系统不能把访问和答卷准确归因到该邀请批次。

#### 跟踪模式的额外限制

跟踪模式必须包含完整的专属邀请链接。如果预览提示“模板未包含完整专属邀请链接”，不能勾选绕过，必须回到模板配置页修正变量映射。

### 第六步：确认创建批次

确认前再次核对对象数量和示例短信，然后点击 **确认创建批次**。系统会冻结本次预览对应的联系人 ID、模板版本和配置版本。

如果确认前有人修改了姓名、单位、分组、模板审核状态或发送配置，系统会提示“名单资料、模板或发送配置已变化，请重新预览”。这时重新预览即可，不能继续使用旧预览。

## 四、首次发送后的批次管理

在 **短信邀请** 列表中，每一行是一个本地批次。常见状态如下：

| 批次状态 | 含义 | 操作建议 |
|---|---|---|
| **待执行** | 已创建，尚未开始执行 | 可以暂停或取消 |
| **发送中** | 正在按分片提交 | 可以暂停后续未提交部分；已提交的短信无法撤回 |
| **已暂停** | 暂停后续未提交任务 | 确认名单或配置后点击“继续” |
| **执行结束** | 本地发送任务已处理完 | 仍需查看送达回执，执行结束不等于全部送达 |
| **已取消待发** | 未提交部分已取消 | 已提交的短信仍按供应商结果保留 |

点击 **详情** 可以查看每条邀请明细。明细将“受理、发送、送达、填写”分开显示：

- **受理**：待发送、提交中、已受理、明确拒绝、结果未知、已排除、已取消。
- **发送**：待处理、发送成功、发送失败、未知。
- **送达**：等待回执、送达成功、送达失败、未知、超时未确认、未发送。
- **填写**（跟踪模式）：未访问、已访问未完成、已完成。

### 发送结果未知时怎么处理

“结果未知”表示网络中断、进程中断、网关响应缺失或返回内容不足以确认是否受理。系统不会自动重发，避免同一联系人收到重复短信。

管理员应先到服务商平台核对任务号、号码和提交时间，再在明细中点击 **核实受理**：

1. 选择“已确认受理”或“已确认未受理”。
2. 如果已受理，填写已核实的云信任务号。
3. 填写核实依据，例如服务商后台查询时间、任务号和结果截图编号。
4. 保存核实结果。

没有充分依据时不要选择“已确认未受理”，也不要直接点击“再次发送明确失败对象”。

## 五、三种常见发送场景

### 场景 A：首轮全量邀请

适用于第一次向全部有效调研对象发送短信。

1. 选择已经确定的匿名或跟踪模式。
2. 短信邀请 → 发送邀请。
3. 选择已审核模板。
4. 对象选择“按分组 / 单位选择”，分组和单位都留空。
5. 执行时间选择“立即进入发送队列”。
6. 预览，确认可发送人数、变量异常人数为 0，短信示例和链接正确。
7. 确认创建批次。
8. 打开详情，观察受理、发送和送达状态。

建议先用“选择具体联系人”创建一个少量试发批次，确认链接能打开、填写能提交、模板内容正确，再做全量发送。

### 场景 B：预约发送

适用于希望在工作日或指定时段发送。

1. 创建批次时选择“预约发送”。
2. 选择北京时间日期和时间。
3. 完成预览并确认创建。
4. 在批次列表确认状态为“待执行”，执行时间正确。
5. 需要提前停止时，点击“暂停”或“取消”。
6. 需要继续时，点击“继续”；系统只会继续处理尚未提交的对象。

预约时间已经过去时不能创建；如果当前时间不在发送时段，任务会等待到下一个允许时段。

### 场景 C：按分组或单位分批发送

适用于先联系重点企业，再联系其他企业。

- 第一批填写“分组=重点企业”，单位留空。
- 第二批填写“分组=一般企业”，单位留空。
- 如果同一分组中只发送某个单位，则同时填写分组和单位。

每次创建都要重新预览。系统会自动排除近期已发送对象，但仍建议在批次名称中写清“重点企业首轮”“重点企业补发”等轮次。

## 六、跟踪模式下的催答流程

催答只适用于 **跟踪邀请进度**。匿名模式对应的按钮名称是“再次邀请”，不具备逐人完成判断。

### 1. 查看完成进度

进入 **调研对象**：

- **未访问**：邀请链接尚未被访问。
- **已访问未完成**：打开过邀请链接，但没有提交问卷。
- **已完成**：通过该邀请链接完成提交，可以点击“查看答卷”。

也可以进入短信邀请 → 批次详情，在“填写”筛选器中选择状态。

### 2. 创建催答批次

在原批次右侧点击 **催答**：

1. 选择短信模板。通常继续使用已审核的邀请模板。
2. 选择“填写筛选”：
   - **全部未完成**：未完成的跟踪对象，包括未访问和访问未完成。
   - **未访问**：只催从未打开链接的人。
   - **已访问未完成**：只催打开过但没有提交的人。
3. 选择立即或预约时间。
4. 点击预览并检查人数和示例短信。
5. 确认创建催答批次。

系统执行前会再次排除已完成、已拒收、已停用、24 小时内已经发送、存在处理中记录和受理结果未知的对象。因此预览人数与最终实际人数可能因执行前状态变化而减少，这是保护机制。

## 七、匿名模式下的再次邀请

在匿名批次右侧点击 **再次邀请**。再次邀请只表示重新发送一轮问卷邀请，系统不能判断某个收件人是否已经通过其他匿名链接填写。

操作时：

1. 选择明确的分组、单位或具体联系人。
2. 查看预览中的排除对象和数量。
3. 发送前由业务人员确认不会对已经填写的人造成重复打扰。
4. 在批次名称中注明“匿名再次邀请”和轮次。

匿名模式的统计只能回答“本批次有多少访问和答卷”，不能回答“哪位联系人完成了问卷”。

## 八、回执同步和送达判断

进入批次详情，点击 **刷新云信回执**。系统会安排正式开放接口查询，之后回到详情刷新页面。

状态判断：

- **送达成功**：服务商回执明确表示送达成功。
- **送达失败**：服务商明确返回送达失败。
- **等待回执**：已经提交或发送成功，但还没有取得送达回执。
- **超时未确认**：超过保留观察时间仍没有确认，不代表一定失败。
- **结果未知**：不能确认短信是否被服务商受理，不得直接重发。

详情中的“导出筛选结果”可以按号码、姓名、单位、受理状态、送达状态和填写状态筛选后导出。导出结果适合做业务跟进名单，不应把“等待回执”当作失败名单。

## 九、回复收件箱和拒收管理

进入问卷左侧 **短信回复**。管理员可看到四个标签页：

### 回复收件箱

1. 管理员点击 **同步回复**，系统安排上行回复同步。
2. 可按号码、回复内容和处理状态查询。
3. 如果回复没有明确问卷归属，管理员点击 **分配**，选择明确对应的问卷后确认。
4. 点击 **处理**，选择“未处理”或“已处理”，填写处理记录。
5. 对明确表示不再联系的号码，点击 **设置拒收** 并填写依据。

普通问卷操作人员只能看到已经明确分配给当前问卷的回复；管理员可以查看全账户回复并负责分配。

### 本地拒收

本地拒收是当前云信账户下的发送前拦截规则，不会修改服务商平台黑名单。启用后，后续所有问卷邀请都会排除该号码。业务人员确认可以恢复联系后，点击 **恢复联系** 并填写依据。

### 待核对回执

当回执缺少完整号码、同一号码存在多次发送或无法唯一匹配时，会进入待核对列表。管理员需要：

1. 打开回执原始信息。
2. 对照批次详情中的本地明细号、号码、云信任务号和时间。
3. 输入正确的本地邀请明细号。
4. 填写人工核对依据并确认关联。

不要仅凭“最近一条发送记录”进行关联，避免把回执写到错误批次。

### 同步运行情况

用于查看送达回执和用户回复的同步游标、当前页、连续失败次数、下次同步时间和最近错误。连续失败时先检查接口配置和网络，不要反复点击发送。

## 十、统计和导出

进入问卷的 **统计** 页面，在邀请回收统计区域可以按邀请批次、分组、单位筛选。

统计指标含义：

| 指标 | 含义 |
|---|---|
| 有效调研对象 | 当前筛选范围内启用且资料有效的对象 |
| 计划邀请对象 | 创建批次时计划选择的对象数量 |
| 实际受邀对象 | 已进入发送尝试的去重对象数量 |
| 逐号发送尝试 | 针对单个手机号的发送尝试次数 |
| 网关请求次数 | 发往服务商的请求次数；一次请求可能包含多个手机号 |
| 已受理 | 服务商明确接受的发送人次 |
| 发送成功 | 网关返回发送成功的人次 |
| 送达成功 | 收到明确送达回执的人次 |
| 明确失败 | 服务商明确拒绝或发送失败的人次 |
| 结果未确认 | 超时、中断或缺少受理依据的人次 |
| 邀请链接访问次数 | 邀请链接被访问的次数；跟踪模式可进一步按对象查看 |
| 通过批次链接提交的答卷 | 使用该批次邀请链接提交的答卷数量 |
| 访问对象人数 | 跟踪模式下至少访问过邀请链接的去重对象数 |
| 完成对象人数 | 跟踪模式下完成提交的去重对象数 |
| 未完成对象人数 | 跟踪模式下尚未完成的对象数 |
| 受邀对象完成率 | 跟踪模式下完成对象数 ÷ 实际受邀对象数 |
| 实际拆分条数 | 以服务商正式返回的 `splitSize` 为准，不使用预览估算 |

匿名模式不会提供逐人完成率，也不能按联系人推断匿名答卷归属。跟踪模式可以点击 **导出未完成名单**，用于线下提醒或后续催答。

## 十一、常见问题处理

### “发送邀请”按钮不可用

检查：问卷是否发布、是否有问卷权限、调研短信能力是否开启、后端是否正常、当前账户是否存在有效云信配置。

### 预览提示变量异常

检查模板正文中的 `#params_N#` 是否连续、映射是否完整，联系人姓名或单位是否超过服务商限制，链接分段是否每段都有值。修改名单或模板后必须重新预览。

### 模板显示“未查询”或运营商覆盖未知

进入短信模板，点击 **查询审核**。如果服务商没有返回某个运营商字段，先由业务人员确认覆盖范围，再在批次预览时勾选“已核对运营商覆盖”。

### 批次执行结束但送达数很少

执行结束只代表本地待发任务处理完，不代表所有号码已送达。打开详情点击 **刷新云信回执**，区分“等待回执、送达成功、送达失败、超时未确认”。

### 同一个人没有出现在催答名单

可能原因：已完成、已拒收、已停用、24 小时内已经发送、存在处理中记录、受理结果未知，或在执行前刚刚完成了问卷。查看预览中的排除原因。

### 想重发结果未知的号码

不要直接重发。先由管理员在服务商平台核实受理结果；只有明确确认未受理，才可按明确失败对象再次发送。

### 需要修改已创建批次中的联系人资料

可以修改联系人当前资料，但已创建批次保存的是模板和联系人快照，不会被修改后的资料悄悄改写。需要重新发送时，应创建新的批次并重新预览。

## 十二、本次问卷的推荐执行清单

针对《青原区营商环境监督参与意向调查》，建议按以下顺序执行：

1. 确认问卷已经发布，外网可以打开填写地址。
2. 在“调研对象”确认选择 **匿名** 还是 **跟踪**。如果需要后续催答，选择跟踪。
3. 在“短信模板”查询审核，核对签名、正文、邀请链接和变量映射。
4. 先选择 1—5 个内部或授权测试号码，创建小批次验证短信内容和链接。
5. 检查测试号码能打开问卷并成功提交；跟踪模式下确认对象状态变为“已完成”。
6. 创建首轮正式批次，建议按分组或单位选择，不要一次混合不同业务范围。
7. 预览后核对人数、异常、排除原因和短信示例，再确认创建。
8. 发送过程中查看批次详情，不要因为暂时“等待回执”而重复创建。
9. 发送完成后刷新回执，按“明确失败”和“结果未确认”分别处理。
10. 跟踪模式在 24 小时后查看未完成对象，使用“催答”；匿名模式只在业务确认后使用“再次邀请”。
11. 在统计页导出结果，在回复页处理上行回复和拒收号码。
12. 将批次名称、实际发送人数、送达人数、完成数和异常处理依据记录到本次调研台账。

## 十三、重要边界

- 发送时间按北京时间和系统配置的发送时段执行。
- 每批最多 1 万名对象，每次服务商请求最多 100 名对象。
- 已提交服务商的短信不能撤回；暂停和取消只影响尚未提交部分。
- 受理未知不等于失败，超时未确认不等于送达失败。
- 匿名模式不提供逐人完成率；跟踪链接也不等于身份认证。
- 本地拒收不会自动修改服务商黑名单。
- 统计中的实际拆分条数只采用服务商正式回执返回值，预览中的拆分数只是估算。
