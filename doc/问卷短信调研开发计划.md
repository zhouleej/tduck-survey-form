# 问卷短信调研闭环开发计划

批准日期：2026-10-26。问卷为业务中心，云信仅承担短信服务。实现依据为《云信平台API接口说明V1.5.4》及 `云信平台调研与完善路线.md`；禁止依赖云信网页登录态和内部接口。

## 交付范围

1. 每份问卷维护万级联系人名单，手机号唯一，姓名、单位、分组、备注；Excel 2MB、1万行预检后确认，可跳过重复或只更新提供的属性。
2. 每份问卷默认匿名，可选跟踪；首个正式批次锁定模式。匿名仅关联批次，不关联答卷与手机号；跟踪邀请可显示访问、完成及关联答卷，填写前提示。
3. 本地短信模板支持绑定、文本模板申请、运营商审核查询、变量映射及预览；现用五段链接等分成非空且最多20字符的片段，新模板优先固定域名加20字符以内的邀请标识。
4. 本地批次最多1万人，每请求最多100人；逐号变量，持久化名单与模板快照，服务端幂等；立即/预约、取消/暂停/继续本地待发送任务。
5. 分离提交、发送、送达、参与状态；正式任务查询分页同步、去重、保留事件；关联歧义待确认；发送超时不自动重发。
6. 跟踪模式人工确认催答，排除已完成、拒收、停用、处理中和受理未知者，执行前复查，默认24小时间隔；匿名只提供再次邀请。
7. 管理员上行收件箱、人工分配及处理；24小时分窗与游标去重；本地账户级拒收，不调用未提供的云信黑名单或回复发送接口。
8. 复用统计页增加邀请回收统计，按人数/尝试/分段分别统计，支持分组单位批次筛选与导出。

## 技术约束

复用 Java8、Spring Boot2.7、MyBatis-Plus、MySQL、Hutool、POI、Vue2、Element UI、现有分页与图表。不增加 Redis、消息队列或新的 UI 框架。数据库认领租约保证多实例执行；提交中断进入未知，不重发；已提交云信不宣称撤回。

接口资源：`/user/form/survey/settings`、`recipients`、`report`；`/user/form/sms/templates`、`batches`、逐号明细、回执同步及催答；管理员回复接口；公开邀请解析与访问接口。旧发送入口纳入相同批次和幂等控制。答卷事务可选关联邀请，原链接及验证码保持兼容。

云信仅用 `/tripartite/task/v2/send`、`task/query`、`template/establishsms`、`template/status`、`upstream`。查询时间字段、成功码、分页和身份字段必须以开放接口联调结果固化；未验证能力默认关闭。不自动切换发送路径、猜测状态或使用网页接口兜底。

发送默认北京时间8—20点，管理员可配置；每分钟扫描、每请求至多100人；回执约1/5/15/60分钟退避后每小时，72小时未确认不等于失败；审核及上行15分钟同步。网络提交不放长事务，恢复不重复发送。

## 数据及权限

持久化调研设置、对象、模板、批次、明细、发送尝试、回执、答卷关联、上行、同步游标、本地拒收与操作审计。联系人修改不改写批次快照；停用不删除历史。新接口先校验问卷存在且未删除，再执行权限检查；跨问卷ID不能越权。令牌只允许填写，不允许查答卷。

## 按功能提交

前后端独立仓库，使用 `feat(模块): 中文描述`、`fix(模块): 中文描述`、`docs(模块): 中文描述`。顺序为文档→协议与日志→名单→模板→邀请关联→持久化批次→预约恢复→回执→催答→回复拒收→统计→部署说明。测试及SQL与对应功能一同提交；不改写原提交、不自动推送。

## 验收与部署

模拟网关覆盖：变量缺失/超长、五段链接、超时未知、同号重复批次、空msgid、歧义匹配、重复及迟到回执、多页查询。实际测试数据库覆盖幂等、认领竞争、答卷事务、万条名单。前端检查构建并验收关键流程、匿名隔离及权限。

提供版本化增量SQL，不覆盖生产数据；功能默认关闭，逐项验证后启用。历史数据不伪造；停用任务保留历史与必要回执核对。端到端验收导入→预览→发送→回执→填写→催答→导出；容量不以万条真实短信验证。
