开发配置位于 `tduck-api/src/main/resources/application-dev.yml`，直接填写本机数据库账号和密码，并随代码提交。无需额外的根目录 `config/` 配置文件或 `TDUCK_DB_*` 环境变量。切换开发环境时，修改该 dev 配置即可。

## 启动

在后端仓库根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/start-dev.ps1
```

脚本先打包，再使用 `dev` 环境启动。如果本地包已更新，可以加 `-SkipBuild`。当前使用 Java 17 和 Maven 3.9.9。启动脚本会隔离从其他项目继承的通用 `SPRING_DATASOURCE_*` 环境变量，仅影响该启动进程，不修改系统环境设置。

在前端仓库根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/start-dev.ps1
```

前端脚本为本机 Node 22 / Webpack 4 添加所需的 OpenSSL 兼容选项，退出后恢复原进程设置。前端端口和代理目标位于 `.env.development`。
